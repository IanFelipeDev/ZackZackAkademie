# Project skills

Vendored from [emilkowalski/skills](https://github.com/emilkowalski/skills) at commit `d16ebe60d09a5ba2afcb7054ede9d0a10c9f6128` (MIT, see each
folder's LICENSE). Only the four web animation skills are included:

- `emil-design-eng`: design engineering and animation principles
- `animate`: builds an animation (tool, properties, curve, duration, reduced motion)
- `find-animation-opportunities`: read-only sweep for where motion helps and where it does not
- `review-animations`: strict review of motion code (only runs when invoked as `/review-animations`)

They mention sibling skills that are not vendored (`improve-animations`, `pick-ui-library`, `animate-expo`).
To update, copy the folders again from a newer commit and review the diff before committing.
